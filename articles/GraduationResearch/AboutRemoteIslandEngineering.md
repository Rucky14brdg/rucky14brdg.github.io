# 概要

離島工学（Remote Island Engineering）とは、離島特有の地理的・社会的条件のもとで、持続可能な地域社会を実現するための技術とその実践を扱う工学の分野。あるいはそれに基づく取り組み。

---
# 定義をめぐって

離島工学は弓削商船高等専門学校（以下、本校）が2017年頃に提唱した概念で、語の初出と考えられる文書としては、[「離島工学を極め地域の活性化へ ~ 島の中ですべてを完結させる力を ~「（『AQUA BOOK』第8号 Vol.3 / SEASON.1, p.13, 2018-04-02）](articles/GraduationResearch/離島工学関係資料/2018_aquabook_season1.pdf)が、現時点で確認できるそれである。ここでは離島工学を、**「離島ならではの問題を解決するために、教授陣の研究力と学生の力の相乗効果により課題を解決していこうという取り組み」** としている。

また[「離島工学に基づく人材育成」（『工学教育』67巻 4号, p33, 2019）](articles/GraduationResearch/離島工学関係資料/離島工学に基づく人材育成_井瀬.pdf)で当時の井瀬校長は、離島工学を **「離島の抱える課題を地域コミュニティと連携し工学的視点から解決すること」** と定義し、本校カリキュラムとして、"課題を見つけることから解決する"ところまで体験させるエンジニアリングデザイン教育としての「離島工学」の実施も報告した。以降、離島工学という語は、本校独自の教育理念として多く用いられている。

そのため、「離島工学」という概念を整理するにあたっては、一工学分野としてのそれと、本校における教育理念・教育実践としてのそれとを区別して考える必要がある。

# 離島工学の原理（核となる視点）

離島工学は、離島における社会システムについて考える。「離島」という条件が、社会システムの設計にもたらす影響としては、とりわけ以下に挙げる2つの概念が重要となる。

1. アクセス構造
2. スケール制約

1の「アクセス構造」については、これは単純な「距離」の問題ではなく、外部資源にアクセスするために必要となるコスト・時間・頻度・不確実性などの構造として考える。
→ これが災害時などの話にも繋がってくる

2の「スケール制約」については、自治体の規模（住民・経済・インフラ）。内陸や都市部では可能なことの一部が、離島では成立しないという前提。

# 「離島」の拡張性

[「竹から始まる資源循環。離島の高専で挑む弓削島の課題解決と、『離島工学』の拡張性」（『月刊高専』, 2026-4-15）](https://gekkan-kosen.com/26132/)の中で森氏が述べているように、離島工学の示す"離島"とは、必ずしも本土から隔絶された島のみに適用されるものではない。

前述の通り離島工学における「離島」という前提は、離島という地理的条件により、外部資源（物的・人的）へのアクセスコストが本土と比較して高いために、その課題解決において内部資源（物的・人的）の活用が相対的に優先・重視されるという、資源制約構造に着眼している。

そのため、離島工学は地理的な離島を対象とする学問にとどまらず、外部資源へのアクセス制約に起因する課題を抱える地域や場面一般へと、その適用範囲を拡張し得る概念であると考えられる。

  >離島における課題を離島にある資源を活用して工学的に解決していくというアプローチ方法は"離島"に限らず、距離が離れているがゆえに課題が発生している場所にも応用していくことができる。
